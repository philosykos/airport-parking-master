# 공항 주차 자동 예약 서비스

인천공항 제2터미널 발렛파킹과 김포공항 국내선 예약주차장의 예약을 돕는 PC용 웹 서비스입니다. 예약 정보 입력부터 반복 예약 요청, 진행 상태 확인, 텔레그램 알림까지 한곳에서 이용할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 인천공항 T2 발렛파킹 예약 | 설정한 간격으로 예약을 요청하고, 성공하면 자동으로 종료합니다. 1회 예약 요청도 지원합니다. |
| 김포공항 국내선 예약주차장 예약 지원 | 제2주차장 주차타워 2·3층의 빈자리를 조회하거나, 예약을 반복 시도해 결제 대기 단계까지 진행합니다. |
| 예약 정보 저장 | 차량번호와 연락처 등 기본 정보를 PC에 저장해 다음 이용 시 불러옵니다. |
| 텔레그램 알림 | 인천 T2의 예약 완료와 김포의 결제 대기 상태를 안내합니다. 어느 화면에서나 헤더의 **설정** 팝업에서 알림 설정 상태를 확인하고 테스트 알림을 보낼 수 있습니다. |

**김포 예약은 사용자가 공항 예약창에서 직접 결제해야 합니다.** 할인 자격 조회는 지원하지 않습니다.

## 시작하기

Python 3.11 이상과 화면을 사용할 수 있는 macOS 또는 Linux PC가 필요합니다. 한 PC에서 한 명의 사용자가 실행하는 환경을 지원합니다.

```bash
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
python3 app.py
```

브라우저에서 [서비스 화면](http://localhost:9000)에 접속한 뒤 이용할 공항을 선택합니다. 김포 예약을 이용하려면 실행 전에 아래 예약 비밀번호를 설정합니다.

- **인천 T2:** 예약 정보를 입력하고 **자동 예약 시작**을 선택합니다. **1회 예약 요청**도 실제 예약을 진행합니다.
- **김포:** 예약 정보를 입력하고 **빈자리 조회** 또는 **자동 예약 시작**을 선택합니다. 결제 대기 상태가 되면 안내 창의 **공항 예약창 보기**에서 결제를 진행합니다. 결제를 마치면 앱이 공항 예약확인 화면을 읽어 예약 완료를 스스로 확인하고, 10초 뒤 예약창을 닫습니다. 결제 단계에서 **중지**를 누르면 확인 창을 거쳐 예약창을 닫고 작업을 끝냅니다. 예약 완료를 확인하지 못하고 끝난 작업은 "종료됨"으로 보이며, 결제했다면 공항 사이트 예약조회에서 확인합니다.

## 설정

프로젝트 루트의 `.env` 파일에 필요한 항목을 입력합니다.

```dotenv
# 김포 예약 이용 시 필수: 영문·숫자 4~128자리
RESERVATION_PASSWORD=yourPassword1234

# 텔레그램 알림 이용 시 설정
TELEGRAM_ALARM_ENABLED=true
TELEGRAM_BOT_TOKEN=봇_토큰
TELEGRAM_CHAT_ID=수신자_또는_채널_ID
```

텔레그램 알림은 기본적으로 꺼져 있으며, 두 공항에 동일한 봇과 수신자를 사용합니다. 알림을 받으려면 봇과 대화를 시작하거나, 수신 채널에 봇을 관리자로 추가하고 메시지 게시 권한을 부여합니다.

조회 간격 등 서비스별 설정은 다음 파일에서 변경할 수 있습니다. 설정을 변경한 뒤에는 앱을 다시 실행합니다.

| 파일 | 설정 항목 |
|---|---|
| [config/t2_valet.toml](config/t2_valet.toml) | 인천 T2 예약 요청과 기본 옵션 |
| [config/gimpo_parking.toml](config/gimpo_parking.toml) | 김포 조회 간격, 브라우저 응답 대기 시간, 저장 경로 |
| [config/notifications.toml](config/notifications.toml) | 텔레그램 알림 전송 재시도 횟수 |

## 이용 안내

- 실행 중인 PC의 브라우저에서 이용하는 로컬 서비스입니다.
- 김포의 결제 대기 상태는 예약 완료를 의미하지 않습니다. 예약 완료 자동 확인은 실제 결제의 완료 화면 구조를 기준으로 만들었지만, 이 기능으로 실제 결제를 끝까지 진행해 보지는 않았습니다.
- 김포 작업을 중지하거나 끝내도 공항 예약이 취소되거나 환불되지 않습니다.
- 예약 결과가 불확실한 경우 공식 사이트에서 예약 내역을 먼저 확인합니다.
